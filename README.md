# Привіт! Я Юлія 👋
### Data Analyst (Аналітик даних)

Вітаю у моєму профілі на GitHub! Я займаюся аналізом даних, дослідженням продуктових метрик та візуалізацією бізнес-показників. Моя мета — трансформувати сирі дані у зрозумілі історії (Data Storytelling), які допомагають бізнесу приймати ефективні рішення.

---

### 🛠️ Професійні компетенції (Hard Skills):
* **Аналітика та методологія:** Аналіз продукту, оцінка ефективності рекламних кампаній, збір та формалізація вимог, очищення та перевірка даних (Data Cleaning & Validation), проведення A/B-тестування.
* **Математична база:** Теорія ймовірностей та математична статистика.
* **Робота з бізнес-метриками:** Розрахунок та відстеження продуктових, маркетингових і фінансових показників (ROI, ROMI, CAC, LTV, Retention, Conversion тощо).
* **Data Storytelling:** Розповідь та презентація інсайтів за допомогою даних для бізнес-замовників.
